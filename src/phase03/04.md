# ヒント: phase03/04

## アクセス修飾子

- `public` — どこからでもアクセスできる（デフォルト）
- `private` — クラス内部からしかアクセスできない
- `protected` — クラス内部と継承先からアクセスできる

```ts
class Example {
  public name: string;
  private secret: number;
}
```

## フィールドの初期値

- フィールドに `= 値` で初期値を設定できる

```ts
class Counter {
  private count: number = 0;
}
```

## implements

- `implements インターフェース名` でクラスがインターフェースを満たすことを宣言する
- インターフェースで定義されたメソッドを実装しないとコンパイルエラーになる

```ts
class Dog implements Animal {
  speak(): void { ... }
}
```
