# ヒント: phase03/01

## 型アノテーション

- 変数名の後に `: 型名` で型を指定する

```ts
let name: string = "Alice";
let count: number = 0;
let active: boolean = true;
```

## 関数の型アノテーション

- 引数と戻り値に型を指定する

```ts
function add(a: number, b: number): number {
  return a + b;
}
```

## void

- 戻り値がない関数の戻り値型には `void` を使う

```ts
function print(msg: string): void {
  console.log(msg);
}
```

## unknown

- どんな値でも代入できるが、使う前に型チェックが必要
- `any` と異なり、型チェックなしに操作するとコンパイルエラーになる

```ts
let val: unknown = 42;
if (typeof val === "number") {
  console.log(val * 2);
}
```
