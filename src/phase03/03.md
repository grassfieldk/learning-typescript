# ヒント: phase03/03

## type エイリアス

- `type` キーワードで型に名前を付ける

```ts
type Direction = "north" | "south" | "east" | "west";
```

## Union 型

- `|` で複数の型を受け付ける型を作る

```ts
type StringOrNumber = string | number;
```

## リテラル型

- 特定の値だけを許容する型
- `"north"` や `42` のように値そのものが型になる

## 判別可能 Union（Discriminated Union）

- 共通のリテラル型プロパティ（kind など）を持たせることで switch での型絞り込みが可能になる

```ts
type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "rectangle"; width: number; height: number };
```

## Intersection 型

- `&` で複数の型を合成した型を作る

```ts
type AB = A & B;
```
