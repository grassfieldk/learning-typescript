# ヒント: phase03/02

## interface

- オブジェクトの形状（プロパティと型）を定義する

```ts
interface User {
  name: string;
  age: number;
}
```

## オプショナルプロパティ

- `?` を付けると省略可能なプロパティになる

```ts
interface User {
  email?: string;
}
```

## readonly

- `readonly` を付けると代入後に変更できないプロパティになる

```ts
interface Product {
  readonly id: number;
}
```

## interface の継承

- `extends` で別の interface を継承し、プロパティを追加できる

```ts
interface Pet extends Animal {
  owner: string;
}
```
