# ヒント: phase02/02

## 名前付きエクスポート / インポート

- `export` を付けると他のファイルからインポートできる

```js
export function add(a, b) { return a + b; }
export const PI = 3.14;
```

- インポート側は `{}` で受け取る

```js
import { add, PI } from "./lib.js";
```

## デフォルトエクスポート / インポート

- 1 ファイルにつき 1 つだけ `export default` が使える

```js
export default "MyApp";
```

- インポート側は任意の名前で受け取れる

```js
import appName from "./lib.js";
```

## Math.round

- `Math.round(値)` で最も近い整数に四捨五入する
- 小数点第 N 位で四捨五入するには `Math.round(値 * 10^N) / 10^N` の形を使う
