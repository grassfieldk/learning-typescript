# ヒント: phase02/01

## Promise

- 非同期処理の結果を表すオブジェクト
- `new Promise((resolve, reject) => { ... })` で作成する
- `resolve(値)` で成功、`reject(値)` で失敗を通知する

## async / await

- `async` を付けた関数は Promise を返す
- `await` で Promise の解決を待ち、結果を受け取る

```js
async function example() {
  const result = await somePromise();
  console.log(result);
}
```

## setTimeout

- 指定ミリ秒後にコールバックを実行する

```js
setTimeout(() => { ... }, 1000);
```

## fetch

- HTTP リクエストを送る組み込み関数
- `response.json()` でレスポンスを JSON としてパースする（Promise を返す）
- `response.ok` が `false` の場合、ステータスコードが 400 以上であることを示す

## try / catch

- `try` ブロック内で例外が発生すると `catch` ブロックに処理が移る

```js
try {
  // ...
} catch (e) {
  console.error(e);
}
```
