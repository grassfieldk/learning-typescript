# ヒント: phase04/01

## typeof による型ガード

- `typeof 値 === "型名"` で型を絞り込む
- `"string"` / `"number"` / `"boolean"` / `"undefined"` などを返す

```ts
if (typeof value === "string") {
  // ここでは value は string 型として扱える
}
```

## カスタム型ガード（型述語）

- 戻り値型を `引数名 is 型名` とすることで型ガード関数を定義できる

```ts
function isString(value: unknown): value is string {
  return typeof value === "string";
}
```

## in 演算子による型ガード

- `"プロパティ名" in オブジェクト` でプロパティの存在を確認し型を絞り込む

```ts
if ("meow" in animal) {
  // ここでは animal は Cat 型として扱える
}
```
