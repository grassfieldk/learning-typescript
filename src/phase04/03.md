# ヒント: phase04/03

## Partial\<T\>

- T のすべてのプロパティをオプショナルにした型を作る

```ts
type PartialUser = Partial<User>;
// → { id?: number; name?: string; ... }
```

## Pick\<T, K\>

- T から K に指定したプロパティだけを取り出した型を作る

```ts
type UserSummary = Pick<User, "id" | "name">;
```

## Omit\<T, K\>

- T から K に指定したプロパティを除いた型を作る

```ts
type UserWithoutContact = Omit<User, "email" | "age">;
```

## ReturnType\<T\>

- 関数型 T の戻り値の型を取得する
- `typeof 関数名` と組み合わせて使う

```ts
type Result = ReturnType<typeof getUser>;
```

## その他のユーティリティ型

- `Required<T>` — すべてのプロパティを必須にする
- `Readonly<T>` — すべてのプロパティを readonly にする
- `Record<K, V>` — キーが K、値が V のオブジェクト型を作る
