# ヒント: phase04/02

## ジェネリクス関数

- `<T>` で型パラメータを宣言し、引数・戻り値の型に使う

```ts
function identity<T>(value: T): T {
  return value;
}
```

## ジェネリクス型

- `type` や `interface` にも型パラメータを持たせられる

```ts
type Pair<K, V> = {
  key: K;
  value: V;
};
```

## 型制約（extends）

- `T extends 型` で T が特定の型を満たすことを要求する

```ts
function getLength<T extends { length: number }>(value: T): number {
  return value.length;
}
```
