# ヒント: phase04/04

## enum（数値）

- メンバーに自動で 0 から連番の数値が割り当てられる

```ts
enum Direction {
  North, // 0
  South, // 1
  East,  // 2
  West,  // 3
}
```

## enum（文字列）

- 各メンバーに文字列を明示的に割り当てる

```ts
enum Status {
  Active = "active",
  Inactive = "inactive",
}
```

## const enum

- コンパイル時にインライン展開される enum
- 実行時に enum オブジェクトが生成されないため軽量

```ts
const enum Color {
  Red,
  Green,
  Blue,
}
```

## enum の使用

- `列挙型名.メンバー名` でアクセスする

```ts
console.log(Direction.North); // 0
console.log(Status.Active);   // "active"
```
