# ヒント: phase01/05

## 分割代入（オブジェクト）

- オブジェクトのプロパティを変数に取り出す

```js
const { name, age } = obj;
```

## スプレッド構文（オブジェクト）

- `...オブジェクト` でプロパティを展開する
- 後から書いたプロパティで同名のものは上書きされる

```js
const updated = { ...obj, newProp: "value" };
```

## for...in

- オブジェクトの列挙可能なプロパティ名を順に取り出す

```js
for (const key in obj) {
  console.log(key, obj[key]);
}
```

## Object.keys / Object.values / Object.entries

- `Object.keys(obj)` — キーの配列を返す
- `Object.values(obj)` — 値の配列を返す
- `Object.entries(obj)` — `[キー, 値]` ペアの配列を返す
