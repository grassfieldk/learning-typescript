# ヒント: phase01/04

## map

- 配列の各要素を変換した新しい配列を返す

```js
array.map(element => 変換後の値)
```

## filter

- 条件に一致する要素だけを含む新しい配列を返す

```js
array.filter(element => 条件)
```

## reduce

- 配列を 1 つの値にまとめる
- 第 2 引数は初期値

```js
array.reduce((accumulator, element) => accumulator + element, 0)
```

## スプレッド構文

- `...配列` で配列を展開する
- 配列の結合や複製に使える

```js
const combined = [...array1, ...array2];
```

## toReversed

- 元の配列を変更せずに逆順の新しい配列を返す
- `reverse()` は元の配列を直接変更するので注意
