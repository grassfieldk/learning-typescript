# ヒント: phase01/02

## if / else if / else

- 条件に応じて処理を分岐する
- 複数の条件は `else if` で連結する

```js
if (条件1) {
  // ...
} else if (条件2) {
  // ...
} else {
  // ...
}
```

## switch

- 1 つの値に対して複数のケースを比較する
- 各 `case` の末尾に `break` を書かないと次の case に処理が流れる
- `default` はどの case にも一致しなかった場合に実行される

## while

- 条件が true の間、繰り返す

```js
while (条件) {
  // ...
}
```

## for...of

- 配列などの反復可能オブジェクトの各要素を順に取り出す

```js
for (const item of array) {
  // ...
}
```
