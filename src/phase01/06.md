# ヒント: phase01/06

## クラスの定義

- `class` キーワードでクラスを定義する

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(`${this.name}!`);
  }
}
```

## 継承

- `extends` で親クラスを継承する
- 子クラスのコンストラクタでは `super()` を呼び出す必要がある

```js
class Dog extends Animal {
  constructor(name) {
    super(name, "Woof");
  }
}
```
