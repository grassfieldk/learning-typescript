# ヒント: phase01/03

## 関数宣言

- `function` キーワードで関数を宣言する

```js
function 関数名(引数1, 引数2) {
  return 値;
}
```

## アロー関数

- `=>` を使った関数式。`function` キーワードを省略できる

```js
const 関数名 = (引数1, 引数2) => {
  return 値;
};
```

- 処理が 1 式のみの場合は `{}` と `return` を省略できる

```js
const 関数名 = (引数1, 引数2) => 値;
```

## デフォルト引数

- 引数に `= 値` を書くと、省略された場合にその値が使われる

```js
function greet(name, greeting = "Hello") { ... }
```

## 可変長引数（rest パラメータ）

- `...引数名` で任意の数の引数を配列として受け取る

```js
function sum(...nums) { ... }
```
